# Leyenda_Verificacion

| Estado | Significado | Regla de uso |
| VERIFICADO | El/los campos indicados coinciden con una fuente trazable. | Puede utilizarse ese campo en cálculos, siempre que sus dependencias también estén verificadas. |
| VERIFICADO PARCIAL | Solo determinados campos del registro están contrastados. | Solo usar los campos enumerados en campos_verificados. |
| CONTRADICTORIO | Hay discrepancia entre dato y fuente o entre fuentes. | No usar el campo afectado para decisiones técnicas hasta resolver la discrepancia. |
| CORREGIDO Y VERIFICADO PARCIAL | Se corrigió un dato que estaba demostrado como erróneo y se verificó el campo corregido. | Usar solo los campos enumerados; conservar trazabilidad del cambio. |
| PENDIENTE | Todavía no se ha contrastado. | No tratar como dato asegurado. |
| REGLA ABSOLUTA | No inventar. | No estimar, completar por familia, copiar de otro modelo, redondear sin indicarlo ni convertir una inferencia en especificación oficial. |
